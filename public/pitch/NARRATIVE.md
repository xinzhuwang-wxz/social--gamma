# 花托邦 路演叙事规格 v3（依据 2026-08-13 团队会议定稿）

> 总时长 5:00。键盘 → 逐页推进；核心链路页内部逐阶段推进。
> 讲稿按下面逐字稿走；页面上 80% 是世界观呈现，讲话 80% 是大白话（会议共识）。

## 结构：痛点(30s) → 起点=种子(20s) → 核心链路(120s) → 花的玩法(45s) → 采种传播(40s) → 校园(30s) → 升华(30s)

---

### P1 封面（开场 hook，~10s）
- 大字：**花托邦**
- 副题：让关系，生长在共同经历上
- 小字：一句愿望，是一段关系的起点
- 视觉：夜色花园全景（产品世界观），萤火、花瓣

**逐字稿**：大家好，我们是花托邦。我们想做一件事——让关系，生长在共同经历上。

### P2 痛点（~30s，1-2 句话点透，不铺垫）
- 主张：**关系不是匹配出来的，是在真实共同经历中养成的。**
- 痛点句：现在的线上社交，把人「匹配」到了一起，却常常停在聊天框里——**真实的行动没有发生**。
- 定位句：我们要解决的，就是从**线上意愿**到**线下真实行动**中间的那道 gap。
- （不踩兴趣匹配半句——会议决定掐掉，不给评委反驳空间）

**逐字稿**：我们相信，关系不是匹配出来的，是在真实共同经历中养成的。但现在的线上社交，把人匹配到一起之后，事情往往就停在聊天框里——真实的行动没有发生。这道从线上意愿到线下行动的 gap，就是我们要解决的问题。

### P3 过渡：行动 = 起点 = 种子（~20s，痛点→世界观的桥）
- 句1：我们以**一次真实行动**作为社交的起点。
- 句2：在花托邦里，这个起点，就是一颗**种子**。
- 句3：社交从起点走到一次真实行动的闭环，就像我们共同把一颗种子，养到开花。

**逐字稿**：怎么解决？我们把一次真实行动，作为社交的起点。在花托邦的世界里，这个起点就是一颗种子。从起点到行动闭环的过程，就像两个人共同把一颗种子养到开花。

### P4 核心链路（~120s，五阶段逐个推进，**没有入林**）
左=大手机（真实界面），右=文案。每按一下长一阶。

| 阶段 | 界面 | 讲述要点 |
|---|---|---|
| 种子 | 播种/澄清 | 说出想做的事，发布就像播种（一句带过） |
| 发芽 | A2A 截图 | 双方成局：两个小花匠 A2A 预热交接。**只放截图，不讲技术** |
| 长叶 | 真人群聊 | 第一次真人对话。**AI 为人服务（human-in-the-loop）**：有主动/被动两种轻推，最终聊与做永远是人 |
| 花苞 | 行动约定 | 聊到的时间地点，整理成一份行动约定，双方确认（生长+花苞合并讲） |
| 开花 | 打卡 | 行动真实发生，回来打卡——花，开了（花瓣动效） |

**逐字稿**：你说出一件想做的事，发布它就像播种。两边的小花匠会先替你们碰一碰——时间对不对得上、地点到不到得了，这一步我们叫发芽。然后是真人对话：AI 在这里只为人服务，卡住的时候轻推一把，主动被动都行，但聊天和决定永远是你们自己。聊到的时间地点，会被整理成一份行动约定，双方各自确认——花苞就结出来了。最后，行动真实发生，你们回来打卡——花，就开了。

### P5 花的玩法（~45s，三点讲完 → 设问过渡）
1. **回忆手账**：这朵花会生成你们的行动回忆手账。
2. **个性化花朵**：上传真实经历，AI 依据经历生成专属形态的花——黑客松长成一棵缀着代码星光的黑松，音乐会开出音符花瓣（展示实际生成图，作为上传经历的激励/bonus）。
3. **花朵升级**：和同一个人再做成几件事，花可以合并升级——关系的递进，看得见。
- （注意口径：**每人只有一个花园**；同一朵花开在两个人各自的花园里。不说「属于你们的花园」）
- 设问过渡：**「一朵花种在你的花园里，它就只是种在那里吗？」**

**逐字稿**：开出来的花有三种玩法。它会生成你们的回忆手账；如果你上传真实经历，AI 会读它，长出一朵专属的花——我们的黑客松长成了一棵缀着代码星光的黑松，音乐会开出了音符花瓣；而你和同一个人做成的事越多，花还会合并升级——关系的递进，看得见。那么问题来了：一朵花种在你的花园里，它就只是种在那里吗？

### P6 采种·传播（~40s，官方口径逐字用）
- 正向（官方句）：**「我们种下的花园里生长出来的花，会成为别人的灵感，然后以种子的形式，在花托邦里传播。」**
- 反向：**「你的小花匠也会主动收集灵感——每当你打开花托邦，信箱里就已经有一些有意思的行动，等着你。」**
- 视觉：小花匠追蝴蝶（放大动效，蝴蝶=带着别家花园种子的信使）＋信箱界面；产品 UI 半透明衬底。

**逐字稿**：不。我们种下的花园里生长出来的花，会成为别人的灵感，然后以种子的形式，在花托邦里传播。反过来，你的小花匠也会主动收集灵感——每当你打开花托邦，信箱里就已经有一些有意思的行动，等着你去做。

### P7 校园（~30s，本页即扣题）
- 当越来越多的行动真实发生，花托邦长成一张**属于校园的行动地图**。
- 校园花期 / 排行榜：此刻谁在哪里，正把什么事做成。
- 扣题句：从线上意愿到线下行动的那道 gap——**在这张地图上，被一朵一朵花填上了。**

**逐字稿**：当越来越多的行动真实发生，花托邦就长成了一张属于校园的行动地图——情人坡上、启真湖边，谁在把什么事做成，都开成了花。还记得开头那道 gap 吗？在这张地图上，它正在被一朵一朵花，填上。

### P8 升华（~30s，回扣社交）
- **花托邦，是一个承载着爱、希望、活力与感动的理想社交空间。**
- 愿每一个来到花托邦的人，都能采集这些美好，带着它们，开启一场新的行动冒险。
- 落款：花托邦 · 让关系，生长在共同经历上

**逐字稿**：花托邦这个名字，来自乌托邦——我们想造一个承载着爱、希望、活力与感动的理想社交空间。愿每一个来到花托邦的人，都能在这里采集这些美好，带着它们，开启一场新的行动冒险。花托邦——让关系，生长在共同经历上。谢谢大家。
